First milestone flow

1. Contract map
Define ABI boundaries for vault, token, oracle, and reward reads without private keys or write calls.
2. Wallet state
Handle disconnected, wrong-network, connected, loading, and rejected-wallet states.
3. Data layer
Use typed Ethers calls, cache intervals, stale-data warnings, and chain-specific providers.
4. UI surface
Render responsive cards, positions, rates, and transaction-disabled safety states.
5. QA gate
Run TypeScript, component state checks, RPC failure handling, and wallet regression scenarios.

Deliverable boundary

  • One responsive dashboard route with wallet/connect state and read-only contract data model.
  • Typed ABI interface layer for public contract reads.
  • RPC fallback, stale-data, loading, empty, and wrong-network states.
  • Integration checklist for MetaMask and WalletConnect.
  • No private keys, no write transactions, and no unaudited production deployment in the first milestone.

Acceptance checks

  • TypeScript build passes.
  • Wallet disconnected and connected states render correctly.
  • Contract read failures produce clear UI states.
  • Data refresh does not block the interface.
  • Mobile and desktop layout remain readable without overlapping text.
